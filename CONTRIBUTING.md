# Contributing to Iris Classification Project

First off, thank you for considering contributing to this educational ML project!

## How Can I Help?

### 🐛 Reporting Bugs
- Check if the bug already exists in issues
- Provide Python version and error traceback
- Include steps to reproduce

### 💡 Suggesting Enhancements
- Explain the educational value
- Provide example implementation if possible
- Consider beginner-friendliness

### 📚 Improving Documentation
- Fix typos or unclear explanations
- Add more learning resources
- Improve code comments

## Development Process

1. **Fork** the repository
2. **Clone** your fork locally
3. **Create a branch** for your changes
4. **Make your changes** with clear commits
5. **Test** your changes work
6. **Push** to your fork
7. **Open a Pull Request**

## Code Style
- Follow PEP 8 guidelines
- Add comments explaining ML concepts
- Keep code beginner-friendly
- Include docstrings for functions

## Project Goals
- Educational clarity over optimization
- Beginner accessibility over complexity
- Practical examples over theory only
- Real-world applications where possible

Thank you for helping others learn ML! 🎓
